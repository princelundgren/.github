# Security

## Reporting a vulnerability

Report it privately with **Report a vulnerability** on the repository's **Security** tab, not in a
public issue, discussion or pull request. Say which file or feature, what an attacker controls and
what they can do with it; steps or a payload that show it help most.

A confirmed issue is fixed on the default branch, and published as a security advisory when it
affects users.

## Supported versions

Only the latest release, or the default branch where a project has no releases.
